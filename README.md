Netflix Data Analysis Using SQL

📌 Project Overview

This project analyzes Netflix movies and TV shows using SQL to understand content distribution, ratings, countries, genres, and content trends.

🛠️ Tools Used

- MySQL
- MySQL Workbench
- SQL

📊 Analysis Performed

- Analyzed Movies vs TV Shows distribution.
- Calculated the percentage distribution of Movies and TV Shows.
- Identified the most common content ratings.
- Analyzed content by release year.
- Explored movie durations and TV show seasons.
- Analyzed directors and actors.
- Examined country-wise content distribution.
- Analyzed genre-wise content.
- Ranked countries using SQL window functions.
- Compared content release years with the years it was added to Netflix.
- Checked data quality, including missing values and duplicates.

💡 Business Insights

- Content type analysis helps understand the balance between movies and TV shows.
- Rating analysis helps identify the most common audience classifications.
- Release-year analysis highlights trends in Netflix's content library.
- Country analysis helps explore the geographical distribution of content.
- Genre analysis helps understand the types of content available.
- Comparing release year with the year added helps examine content acquisition patterns.

🧠 SQL Concepts Used

- SELECT, WHERE, GROUP BY, ORDER BY
- Aggregate Functions
- CASE Statements
- Subqueries
- Date Functions
- String Functions
- Window Functions ("RANK()")
- Data Quality Checks

🎯 Project Objective

The objective of this project is to practice SQL and extract meaningful insights from Netflix content data.

✅ Conclusion

This project demonstrates practical SQL skills through data exploration, aggregation, ranking, and trend analysis using a Netflix dataset.
